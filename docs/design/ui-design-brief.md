## 一、项目背景

**产品名称**：TadpolesAI  
**产品定位**：AI 驱动的简历优化 SaaS 平台，帮助求职者通过 AI 生成、优化简历，提升面试邀请率。  
**目标用户**：中国求职者，以年轻白领、应届生为主。  
**技术栈**：前端 React + TypeScript，后端 Go 微服务。

**Stitch 项目地址**：  
`https://stitch.withgoogle.com/projects/16932619638238655312`

## 三、设计规范（必须遵守）

### 3.1 品牌色彩

| Token | 色值 | 用途 |
|-------|------|------|
| Primary | `#0891B2`（Cyan-600） | 主操作按钮、链接、高亮 |
| Primary Dark | `#0E7490` | 按钮 Hover 态 |
| Primary Light | `#CFFAFE` | 背景浅色区域、Chip |
| Navy | `#023047` | 左侧暗色面板、深色背景 |
| Page BG | `#F0F9FF` | 页面背景 |
| Text Primary | `#0C4A6E` | 正文标题 |
| Text Secondary | `#64748B` | 辅助文字、标签 |
| Border | `#BAE6FD` | 输入框、卡片边框 |
| Success | `#16A34A` | 已优化、成功态 |
| Warning | `#D97706` | 优化中、警告态 |
| Error | `#DC2626` | 错误、积分不足 |

### 3.2 字体

- **字体族**：Inter（英文）+ 系统中文字体
- **字号规范**：
  - 页面大标题：28–32px，Bold
  - 卡片标题：16–18px，Semi Bold
  - 正文：14–15px，Regular
  - 辅助文字：12–13px，Regular
  - 按钮文字：14–15px，Semi Bold

### 3.3 圆角

| 元素 | 圆角 |
|------|------|
| 主按钮 | 10–12px |
| 卡片 | 14–16px |
| 输入框 | 8–10px |
| Chip / 标签 | 全圆（pill） |
| 头像 | 全圆 |

### 3.4 阴影

- 卡片默认阴影：`0 4px 20px rgba(0, 46, 89, 0.10)`
- 按钮悬浮阴影：`0 4px 12px rgba(8, 145, 178, 0.30)`

### 3.5 间距节奏

- 页面左右边距：80px
- 卡片内边距：24px
- 组件间距：16 / 24 / 32px（8 的倍数）
- Navbar 高度：64px

### 3.6 通用组件规范

**主按钮（Primary Button）**
- 背景：`#0891B2`，文字白色，圆角 10px，高度 48px，带阴影
- Hover：背景加深至 `#0E7490`

**次要按钮（Secondary Button）**
- 背景：`#CFFAFE`，文字 `#0891B2`，无阴影

**输入框**
- 背景白色，边框 `#BAE6FD` 1.5px，聚焦时边框变 `#0891B2`，圆角 8px，高度 50px

**导航栏**
- 白色背景，底部 1px `#BAE6FD` 分割线，Logo 左对齐，Nav 链接居中，积分 Chip + 头像右对齐
- 当前选中项文字用 Primary 色，下方 3px Primary 色下划线

**卡片**
- 白色背景，14–16px 圆角，统一卡片阴影，内边距 24px

## 五、Stitch MCP 操作指南

### 5.1 环境准备

在终端执行前，先设置代理（Stitch 需要代理才能访问）：

```bash
export https_proxy=http://127.0.0.1:6789
export http_proxy=http://127.0.0.1:6789
export all_proxy=socks5://127.0.0.1:6789
```

确认 Stitch MCP 已连接：

```bash
claude mcp list
# 应看到：stitch: https://stitch.googleapis.com/mcp (HTTP) - ✓ Connected
```

### 5.2 进入项目

Stitch 项目 ID：`16932619638238655312`  
项目 URL：`https://stitch.withgoogle.com/projects/16932619638238655312`

通过 MCP 工具进入该项目后，按以下顺序依次生成各页面。

### 5.3 设计顺序

1. **登录 / 注册页** → 确认视觉风格，后续页面与之保持一致
2. **控制台** → 确立导航栏组件，后续复用
3. **简历编辑器** → 最复杂的页面，三栏布局
4. **积分中心** → 相对独立，复用导航栏和卡片组件

### 5.4 每个页面的提示词模板

向 Stitch 描述页面时，使用以下结构：

```
设计一个 [页面名称]，要求：
- 整体风格：现代 SaaS 风格，主色 #0891B2（青色），背景 #F0F9FF
- 布局：[具体布局描述]
- 包含以下元素：[元素列表]
- 字体：Inter，中文使用系统字体
- 确保与已有的登录页/控制台页风格统一（导航栏、按钮、卡片样式一致）
```

### 5.5 质量检查清单

每个页面完成后检查：
- [ ] 色彩是否符合规范（主色 #0891B2，不要用其他蓝色系替代）
- [ ] 字体大小层次是否清晰（标题/正文/辅助 三级）
- [ ] 间距是否统一（基于 8px 网格）
- [ ] 交互状态是否完整（按钮、输入框的正常/Hover/聚焦态）
- [ ] 中文文案是否正确（见各页面数据）
- [ ] 导航栏组件是否与其他页面完全一致
- [ ] 卡片阴影和圆角是否统一

## 六、背景参考

**架构概览**：TadpolesAI 由 5 个微服务组成：
- **LLM Gateway**：统一 AI 调用入口，多厂商 Key 池
- **Billing Service**：积分账户管理，预扣费结算
- **User Service**：用户认证，JWT 双 Token
- **Resume Agent**：简历业务逻辑，AI 编排
- **APISIX**：API 网关，JWT 鉴权，限流

**主要用户流程**：
1. 用户注册/登录 → 获得初始免费积分
2. 进入控制台 → 查看/管理简历列表
3. 新建或编辑简历 → 在编辑器中填写内容
4. 触发 AI 优化 → 消耗积分，获得优化建议
5. 积分不足 → 跳转积分中心充值
6. 导出 PDF → 完成简历
